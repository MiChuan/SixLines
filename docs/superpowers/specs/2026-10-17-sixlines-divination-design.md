# SixLines 龟甲六爻占卜站 — 设计规格

**日期:** 2026-10-17  
**状态:** 待用户审阅  
**形态:** 纯前端 SPA，部署至 GitHub Pages；附可安装 Agent Skill

## 1. 目标与非目标

### 目标

打造沉浸式「仪式剧场」单页体验：程序化 3D 龟甲与开元通宝、装币/摇爻动效与音效、完整三钱六爻（含动爻变卦）、卦辞解析、六十四卦查询，以及结合天干地支的文言用事断语（宜/慎/忌）。支持 GitHub Pages 静态部署，并提供可在 Codex / Cursor / Workbuddy 安装的便携 Skill。

### 非目标

- 不做用户账号、云端占卜历史、社交分享后端
- 不做真实算命承诺；页脚明确文化体验免责声明
- 不引入外部付费 3D 资产或大型音频素材包
- 不做服务端鉴权或 API

## 2. 已确认决策

| 项 | 选择 |
|----|------|
| 交付形态 | 纯前端 SPA（Vite + TypeScript + Three.js） |
| 起卦 | 三枚开元通宝，完整老阴/少阳/少阴/老阳，本卦+变卦 |
| 视觉 | 墨金古卷（深墨、鎏金、裂纹、烛光感） |
| 断语风格 | 仪式化文言 |
| 3D 模型 | 全部程序化建模 |
| 体验架构 | 方案一：仪式剧场（单页祭坛） |
| 部署 | GitHub Pages |
| 附带产物 | 跨宿主可安装 Skill |

## 3. 体验流程

单页即一座祭坛，状态机驱动：

1. **问事** — 居中输入占卜事宜；显示今日干支；可选点选用事类别（功名/求财/出行/婚恋/健康/诉讼/其他）
2. **装币** — 三枚通宝弧线落入龟甲空腔，金属碰撞声
3. **摇爻 ×6** — 龟甲摇晃 → 三币飞出落地定面 → 记一爻 → 收回再摇（自下而上）
4. **成卦** — 六爻竖列点亮；有动爻则同时显本卦与变卦
5. **断辞** — 卦辞/动爻爻辞/象理解析 + 干支用事文言断语（宜/慎/忌）
6. **查卦** — 角落「六十四卦」全屏卷轴：搜索、浏览、单卦详情；可「以此卦演示」静态展示

**首屏构成:** 品牌「六爻」、一句问事引导、龟甲与主 CTA。不做仪表盘式信息堆砌。

**边界:** 未问事也可摇卦，但干支断语会提示补全事宜或类别；摇卦中不可重入；「再占」清空重来；全局静音；首次用户手势后解锁音频。

## 4. 技术架构

```
src/
  main.ts                 # 入口
  app/state-machine.ts    # 仪式流程状态机
  scene/                  # Three.js：场景、龟甲、通宝、动画时间轴
  divination/             # 三钱算法、本卦/变卦、随机源
  calendar/               # 公历→干支（年/月/日柱）
  judgment/               # 用事五行映射 + 生克 → 宜/慎/忌文言
  data/hexagrams.json     # 64 卦卦辞/爻辞/解析
  audio/                  # Web Audio 合成器
  ui/                     # 轻量 DOM：输入、结果、卷轴、静音
skills/sixlines-divination/  # 便携 Agent Skill（见 §8）
```

- **无重型 UI 框架**；DOM 仅承载文字与控件，3D 为视觉锚点
- **随机:** `crypto.getRandomValues`；开发可切固定种子复现动画
- **三钱映射:** 字(阳)=3，背(阴)=2；和为 6/7/8/9 → 老阴/少阳/少阴/老阳

## 5. 3D 与音效

### 模型

- **龟甲:** 椭球壳体 + 背甲分区裂纹法线；烛光感环境；轻微呼吸浮动
- **开元通宝:** 扁圆柱 + 方孔；一面浮雕「开元通宝」，一面光背；青铜金 PBR

### 动效时间轴

| 阶段 | 行为 | 时长约 |
|------|------|--------|
| 装入 | 三币弧线入甲，微弹，错开 120–180ms | ~1.2s |
| 摇晃 | 龟甲衰减摆动，腔内币抖动 | 1.2–1.6s |
| 摇出 | 甲口倾斜，三币抛物线飞出翻滚定面（结果预计算，动画贴合） | ~1.5s |
| 成爻 | 爻符浮现（动爻标 ○/×），币收回 | ~0.8s |
| 终局 | 六爻点亮，卦名鎏金；变卦侧翼淡入 | ~1.5s |

### 音效

Web Audio 合成：装币叮声+空腔闷响、摇晃低频摩擦、落地错落撞击、成卦低沉钟鸣。可静音。

## 6. 卦理与干支断语

### 数据

`hexagrams.json` 每卦含：序号、卦名、上下经卦、卦辞、六爻爻辞摘要、文言短解析。结果页顺序：本卦 → 动爻爻辞 → 变卦（若有）→ 象理解析。

### 干支用事

1. 本地时区取当日年/月/日柱天干地支  
2. 事宜文本关键词 → 五行；失败则用用户点选类别  
3. 日柱五行 vs 用事五行生克 + 本卦吉凶倾向 → **宜 / 慎 / 忌** + 一句文言断语  
4. 页脚免责：文化体验，非决策依据

## 7. GitHub Pages 部署

- Vite `base` 设为 `/${repoName}/`（仓库名 `SixLines` → `/SixLines/`），本地 `base: '/'` 可通过 env 区分
- `npm run build` 输出 `dist/`
- GitHub Actions：push 到 `main` 时构建并部署 `dist` 到 `gh-pages` 或 `actions/deploy-pages`
- README 写明：仓库 Settings → Pages 启用；首次开启 Pages 权限
- 相对路径加载 JSON/字体/资源，避免绝对根路径在子路径下 404

## 8. 便携 Agent Skill

### 目的

Skill 名称：`sixlines-divination`  
教 Agent：**维护/扩展本站**时遵循的卦理约定、状态机边界、数据格式与视觉/动效约束；以及按本站规则解释六爻结果时的表述规范。不替代网站本身，不代用户「在线摇卦」伪造神秘权威。

### 包结构（仓库内，一套多宿主）

```
skills/sixlines-divination/
  SKILL.md                 # name + description + 核心流程
  agents/openai.yaml       # Codex UI 元数据（可选字段）
  references/
    hexagram-rules.md      # 三钱、动爻、变卦
    gan-zhi-judgment.md    # 干支用事规则摘要
    scene-conventions.md   # 3D/动效/音效约定
  INSTALL.md               # Codex / Cursor / Workbuddy 安装步骤
```

### 安装约定

| 宿主 | 安装方式 |
|------|----------|
| **Cursor** | 复制或 symlink 到 `~/.cursor/skills/sixlines-divination/`，或保留仓库内 `.cursor/skills/` 项目级引用 |
| **Codex** | 复制到 `$CODEX_HOME/skills/sixlines-divination/`（或用户 skills 目录）；保留 `agents/openai.yaml` |
| **Workbuddy** | 按其 Skill 目录约定复制同一文件夹（`SKILL.md` 为入口）；`INSTALL.md` 写明探测路径与「若目录不同则询问用户」 |

Skill 正文保持宿主无关；仅 `INSTALL.md` 与 `agents/openai.yaml` 承载宿主差异。

### Skill 触发

Description 含：六爻、龟甲、开元通宝、三钱起卦、变卦、干支用事、SixLines、维护占卜站。  
维护站点或按本站规则解读卦象时加载；普通闲聊不算命时不加载。

## 9. 模块边界（可测试单元）

| 单元 | 职责 | 依赖 |
|------|------|------|
| `divination` | 三钱→爻→本卦/变卦 | 无 UI |
| `calendar` | 日期→干支 | 无 UI |
| `judgment` | 事宜+干支+卦→断语 | divination 结果、calendar |
| `state-machine` | 仪式阶段转换 | 上述纯函数 |
| `scene` | 渲染与动画，结果由外部注入 | state-machine 事件 |
| `audio` | 合成音效 | 用户手势门闩 |
| `ui` | DOM 输入/结果/卷轴 | state-machine |

纯逻辑（起卦、干支、断语）必须可单测，不依赖 Three.js。

## 10. 错误与降级

- WebGL 不可用：展示静态 SVG/Canvas 龟甲示意 + 仍可文字起卦
- 音频被拒：静默继续，控件显示已静音
- 事宜无法映射五行：强制类别选择后再出断语
- 小屏：3D 缩小居中，结果以底部抽屉展开；64 卦卷轴全屏列表

## 11. 成功标准

1. 可完成完整六次摇爻并正确显示本卦/变卦与卜辞  
2. 装币、摇晃、飞出、成卦动效连贯且有音效（可关）  
3. 64 卦可搜索浏览  
4. 输入事宜后给出宜/慎/忌文言断语（含当日干支）  
5. `npm run build` 产物可部署 GitHub Pages 且子路径资源正常  
6. `skills/sixlines-divination/` 可按 INSTALL 装入三宿主，且描述可被发现
